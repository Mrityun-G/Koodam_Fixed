KOODAM is a service marketplace platform (A Mobile Application) that connects customers with trusted service providers through a seamless digital experience.
It offers user authentication, service discovery, booking management, online payments, and real-time order tracking.
The platform includes dedicated dashboards for customers and service partners, with emergency support and intelligent service recommendations.
Built using React,Supabase and Capacitor, KOODAM aims to simplify service booking and delivery.
